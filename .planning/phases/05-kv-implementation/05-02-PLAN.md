    Note: This is under `root` directly (not `metaSubspace`) — KV is a top-level subspace alongside "log", "tag", "meta".

    4. Add KV method overrides after `getLatestSeqnumForTag()`:
    ```java
    @Override
    public void setTagValue(LogTag tag, String key, byte[] value) {
        db.run(tr -> {
            tr.set(kvSubspace.pack(Tuple.from(tag.namespace(), tag.key(), key)), value);
            return null;
        });
    }

    @Override
    public byte[] getTagValue(LogTag tag, String key) {
        return db.run(tr ->
            tr.get(kvSubspace.pack(Tuple.from(tag.namespace(), tag.key(), key))).join()
        );
    }

    @Override
    public void deleteTagValue(LogTag tag, String key) {
        db.run(tr -> {
            tr.clear(kvSubspace.pack(Tuple.from(tag.namespace(), tag.key(), key)));
            return null;
        });
    }
    ```

    Note: These overrides do NOT declare `throws IOException` — FDB operations don't throw checked exceptions. The interface default throws IOException; overrides may narrow the exception contract.
