  <action>
    Two changes in this file:

    1. Fix readByTag() (lines 95–112): Replace the loop that iterates all tag index values with a tailMap seek:

    BEFORE (buggy — O(N) linear scan):
    ```java
    List<LogEntry> result = new ArrayList<>();
    for (long seqnum : idx.values()) {
        if (seqnum >= fromSeqnum) {
            LogEntry e = log.get(seqnum);
            if (e != null) result.add(e);
        }
    }
    result.sort((a, b) -> Long.compare(a.seqnum(), b.seqnum()));
    return Collections.unmodifiableList(result);
    ```

    AFTER (correct — O(log N) seek + O(K) iteration):
    ```java
    NavigableMap<Long, Long> range = idx.tailMap(fromSeqnum, true);
    List<LogEntry> result = new ArrayList<>(range.size());
    for (long seqnum : range.keySet()) {
        LogEntry e = log.get(seqnum);
        if (e != null) result.add(e);
    }
    // No sort needed: ConcurrentSkipListMap.tailMap preserves ascending key order
    return Collections.unmodifiableList(result);
    ```

    The sort is no longer needed because tailMap on a ConcurrentSkipListMap preserves ascending key order.

    2. Fix the wrong Javadoc on the tagIndex field (around line 31–35). The comment says
    "Per-tag index: tag → (localId → seqnum)" but the actual implementation stores seqnum as both
    key and value (see append() line 73: .put(entry.seqnum(), entry.seqnum())).
    Correct the comment to accurately describe the structure:
    "Per-tag index: tag → (seqnum → seqnum). Keys and values are both the global seqnum;
    using seqnum as key enables O(log N) positional seeks via tailMap."

    Do NOT change the logic of append(), trim(), or any other method. Do NOT add NavigableMap
    as a new import if it is already present (it's in java.util.NavigableMap — check imports first).

    void readByTag_fromSeqnum_skipsEntriesBelowBoundary() throws IOException {
        // Non-contiguous seqnums — simulates actor replay from a mid-log checkpoint
        adapter.append(entry(0,  0, TAG_A, "e0"));
