    **BatchingPersistenceAdapter.java** — add after `getLocalIdCountForTag()` in the Metadata section:

    ```java
    @Override
    public long getLatestSeqnumForTag(LogTag tag) throws IOException {
        long delegateLatest = delegate.getLatestSeqnumForTag(tag);
        // Check pending buffer for any higher seqnum for this tag
        List<LogEntry> snapshot = pendingSnapshot();
        long pendingLatest = -1L;
        for (LogEntry e : snapshot) {
            if (e.tags().contains(tag) && e.seqnum() > pendingLatest) {
                pendingLatest = e.seqnum();
            }
        }
        return Math.max(delegateLatest, pendingLatest);
    }
    ```

    Pending entries always have higher seqnums than flushed entries (same guarantee as getLatestSeqnum()),
    so this correctly returns the overall latest.

    **FoundationDBPersistenceAdapter.java** — four changes:

    1. Add field after `tagLocalIdCount`:
    ```java
    /** Per-tag latest seqnum cache; mirrors tagcount subspace but tracks seqnum instead of localId count. */
    private final ConcurrentHashMap<LogTag, AtomicLong> tagLatestSeqnum = new ConcurrentHashMap<>();
    ```

    2. Add subspace constant after TAGCOUNT_NS:
    ```java
    private static final String TAGLATEST_NS = "taglatest";
    ```

    3. Add subspace field after `tagCountSubspace`:
    ```java
    private Subspace tagLatestSubspace;
    ```

    4. In `initSubspaces()`, add:
    ```java
    tagLatestSubspace = metaSubspace.subspace(Tuple.from(TAGLATEST_NS));
    ```

    5. In `loadMetadata()`, after the tagcount loading loop, add a parallel loop:
    ```java
    Range tlRange = tagLatestSubspace.range();
    for (KeyValue kv : tr.getRange(tlRange)) {
        Tuple suffix = tagLatestSubspace.unpack(kv.getKey());
        String ns  = suffix.getString(0);
        String key = suffix.getString(1);
        long latest = ByteBuffer.wrap(kv.getValue()).getLong();
        tagLatestSeqnum.put(LogTag.of(ns, key), new AtomicLong(latest));
    }
    ```

    6. In `commitChunk()`, inside the FDB transaction loop (after updating tagcount), add:
    ```java
    long newLatest = entry.seqnum();
    tr.set(
        tagLatestSubspace.pack(Tuple.from(tag.namespace(), tag.key())),
        longBytes(newLatest)
    );
    ```
    Note: Since seqnums are monotonically increasing and commitChunk processes entries in seqnum order,
    the last entry for a tag will always have the highest seqnum — no max() needed inside the loop.
    However, if a single chunk has multiple entries for the same tag, only the last write wins in FDB,
    which is correct because it has the highest seqnum.

    7. In `commitChunk()`, after the transaction commits, in the in-memory cache update loop, add:
    ```java
    for (LogTag tag : entry.tags()) {
        tagLocalIdCount...  // existing
        tagLatestSeqnum
            .computeIfAbsent(tag, k -> new AtomicLong(-1L))
            .updateAndGet(c -> Math.max(c, entry.seqnum()));
    }
    ```

    8. Add `getLatestSeqnumForTag()` after `getLocalIdCountForTag()`:
    ```java
    @Override
    public long getLatestSeqnumForTag(LogTag tag) {
        AtomicLong c = tagLatestSeqnum.get(tag);
        return c == null ? -1L : c.get();
    }
    ```

    Do NOT override the `throws IOException` signature — FDB's implementation does not throw.
    The interface declares `throws IOException`; Java allows overrides to omit or narrow checked exceptions.

    ```java
    void getLatestSeqnumForTag_includesPendingEntries() throws IOException {
        // Append but do NOT flush — entries live in pending buffer only
        adapter.append(entry(0, 0, TAG, "e0"));

    void getLatestSeqnumForTag_afterFlush_returnsFromDelegate() throws IOException {
    ```

    ```java
    void subscribeTail_receivesOnlyFutureEntries() throws Exception {
        LogView view = service.getView(ORDERS);

        // Pre-populate — subscribeTail should NOT deliver these
        service.append(AppendRequest.to(ORDERS, "past-1".getBytes())).join();
        service.append(AppendRequest.to(ORDERS, "past-2".getBytes())).join();

        List<String> received = new java.util.concurrent.CopyOnWriteArrayList<>();
        SharedLog.Subscription sub = view.subscribeTail(
                e -> received.add(new String(e.dataUnsafe()))
        );

        try {
            // Append future entries after subscribeTail()
            service.append(AppendRequest.to(ORDERS, "future-1".getBytes())).join();
            service.append(AppendRequest.to(ORDERS, "future-2".getBytes())).join();

            await().atMost(3, java.util.concurrent.TimeUnit.SECONDS)
                   .until(() -> received.size() == 2);

            assertThat(received).containsExactly("future-1", "future-2");
            assertThat(received).doesNotContain("past-1", "past-2");
        } finally {
            sub.close();
        }
    }
    ```
